Four tools, four answers.

A store here, a distro repo there, a formula in Homebrew, a CLI tool stashed inside some container. Finding one thing means asking each tool in turn, in its own syntax, and remembering which one had the answer.

pkgfind asks all of them together and ranks what comes back as a single list.

Without it

flatpak search firefox
dnf search firefox
brew search firefox
distrobox enter fedora-toolbox -- dnf search firefox

Four syntaxes, four result formats, and no way to compare them.

With it

pkgfind firefox

Everything Flatpak, Homebrew, RPM and that container know about, ranked as one list — each result installable where it sits.

It only lights up what you already have.

Every back end checks for its own tool and bows out when it isn’t there, so nothing needs enabling and there is no config file. On atomic Fedora it reaches for rpm-ostree rather than dnf, because that is the real install path.

Ranked together, installed in place.

An exact match floats to the top wherever it lives. The badge tells you which source a result came from; choosing one runs that source’s real install command and streams the output back live.

The Linux app, built with GTK4 and libadwaita. Windows gets its own native front end over the same search, and pkgfind -c answers in the terminal on any of them.

One ranked list

Results from every source are merged and sorted by how well they match, so an exact hit anywhere beats a partial one and the obvious answer stays on top.

Install and update from the row

Pick a result and pkgfind runs flatpak install, brew install or winget install for you, output streaming as it goes. The Updates view gathers everything upgradable across all your sources: update one, or all of them.

Already installed, and where

Anything on the machine is marked as installed on its own row, so a duplicate you picked up from two sources is obvious at a glance, and removing it is the same one click.

No GUI required

Run pkgfind -c firefox for the same merged search as plain terminal output — useful over SSH, or when the machine has no desktop at all.
