The problem

Your apps come from everywhere.

Store here, distro repo there, a formula in Homebrew, a CLI tool stashed in some container. Finding one thing means asking each tool in turn — and remembering which is which.

flatpak search firefox
dnf search firefox
brew search firefox
# ...and which distrobox was it in again?

The old way — four tools, four answers.

→
pkgfind firefox
→ 41 results across Flatpak, RPM and Homebrew, ranked together

What it does

Search once. Install from the result.

One ranked list

Every source is merged and sorted by how well it matches — an exact hit from any source beats a partial one, so the obvious answer is always on top.

Install & update

Pick a row and pkgfind runs that source's real command — flatpak install, brew install, winget — streaming the output live. The Updates view rolls up everything upgradable across sources: update one app, or all of them.

Only what you have

Each back end checks whether its tool exists and quietly bows out if not. Nothing to enable, no config file — it just fits the machine it's on.

Native on every OS

A libadwaita app on Linux and macOS, a native front end on Windows, and a fast -c terminal mode everywhere in between.
