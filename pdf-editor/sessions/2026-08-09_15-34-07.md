# Session 2026-08-09 — Build PDF Editor desktop app

## Goal
Build a PDF editor app from scratch, using PDF Expert (Readdle) as the feature
reference. Mid-session requirements: modern/professional UI, and "a normal app,
not a webapp" → converted to an Electron desktop app.

## What was built
New project `pdf-editor/`: offline PDF editor. pdf.js 3.11.174 renders
(canvas + selectable text layer + custom AcroForm layer), pdf-lib 1.17.1 writes
real edited PDFs. Vanilla ES modules, no build step, vendored libs (fully
offline). Electron 43 shell added on top; the same code still runs in a browser
via `run.sh`.

Features: text markup (highlight/underline/strikeout via text selection), pen,
shapes (rect/ellipse/line/arrow), text boxes, sticky notes (real /Text
annotations), images, signature pad (localStorage, reusable), AcroForm filling
(text/checkbox/radio/dropdown — values written into the saved file), page ops
(rotate/reorder via drag/delete/extract/blank/merge), search with match
highlighting, outline nav, Day/Night/Sepia, undo/redo, dark pro UI.
Annotations are stored in PDF user-space coords so they survive zoom/rotation
and are drawn 1:1 by pdf-lib on save (two save paths: in-place when page
structure unchanged, rebuild-by-copy otherwise).

## Key files
- `index.html`, `css/app.css` — UI shell + dark theme (CSP meta included)
- `js/state.js|ui.js|viewer.js|tools.js|pages.js|save.js` — app modules
- `electron/main.cjs`, `electron/preload.cjs` — window, native open/save
  dialogs, argv/single-instance file opening, unsaved-changes close guard,
  `PDFED_TEST=1` self-check hook
- `scripts/make-sample.cjs` → `sample.pdf` (3 pages incl. interactive form)
- `run.sh` (browser mode), `README.md`, `assets/icon.svg`
- Installed outside repo: `~/.local/bin/pdf-editor` (execs the Electron ELF
  directly), `~/.local/share/applications/pdf-editor.desktop` (MimeType
  application/pdf), hicolor icon.

## Testing (all passed)
Headless e2e via puppeteer-core + CDP against flatpak Chromium: real mouse
drawing of annotations, form filling, save/extract byte capture, node-side
pdf-lib validation, round-trip re-render of the saved file. Electron self-check
renders sample with text layer. Bugs found & fixed this way: CSS overriding the
`hidden` attribute; global icon `svg` rule squashing the overlay SVG (scoped
with `:where()`); mousedown focus-steal deleting fresh text boxes.

## Gotchas worth remembering
- `--virtual-time-budget` breaks the pdf.js worker (doc never loads) — use real waits.
- Claude Code harness kills spawned children when a Bash call ends — launch GUI
  apps via `i3-msg exec`.
- Homebrew node isn't on PATH outside the shell → launcher must exec
  `node_modules/electron/dist/electron` directly (this was why the app
  "wasn't opening" from the .desktop entry).

## Open items
- Non-Latin text boxes fall back to `?` substitution (Helvetica/WinAnsi) —
  embedding a Unicode font (e.g. Noto) via fontkit would fix it
- No OCR / Office conversion / true redaction (roadmap in README)
- Window icon PNG for Electron not set (only .desktop SVG icon)
